# 마이크 입력 테스트용 음성 데이터 제작

상태: 최종

## 목표
사람이 직접 마이크에 말할 수 없는 상황에서도, 생성한 음성 데이터를 사용해 마이크 입력을 테스트할 수 있도록 한다.

## Astra에 맡길 범위
macOS에서 사용할 테스트 음성 생성·재생 패키지를 실제로 구현하고, OpenAI API를 사용해 샘플 음성 데이터를 생성한다. 가상 마이크를 통한 테스트 입력 설정과 사용 절차도 제공한다.

## 요청한 산출물과 요구사항
- 테스트용 음성 데이터를 제작하는 별도 패키지를 만든다.
- 음성 데이터 제작에 OpenAI API 키를 사용한다.
- 샘플 음성은 한국어와 영어로 생성하며, 서비스 용도에 맞는 발화 내용은 Astra가 선정한다.
- 생성 파일은 기존 서비스의 오디오 규격에 맞춰 WAV 컨테이너, 24,000Hz, 모노, signed 16-bit little-endian PCM으로 저장한다.
- 생성한 음성 데이터를 마이크 입력 테스트에 활용한다.
- 별도 모듈에서 생성한 음성을 재생하고, 가상 마이크를 통해 기존 서비스의 마이크 입력으로 전달한다.
- 테스트를 수행하는 사람이 따라 할 가상 마이크 설정 및 음성 입력 절차를 제공한다. 음성 생성, 가상 마이크 입력 장치 선택, 서비스의 마이크 기능 시작, 테스트 음성 재생 과정을 포함한다.

## 제약
- 테스트 환경은 macOS다.
- 기존 서비스에 테스트 목적으로 추가하는 코드는 최소화한다.
- 테스트를 위한 별도 모듈 제작은 허용한다.

## 확인한 기존 서비스와 참고 코드
- `packages/audio-client/src/browser-source.ts`: `getUserMedia`로 마이크를 캡처한다. 현재 캡처 코드에 `deviceId` 지정은 없으므로, 사용 절차에는 macOS 또는 브라우저에서 가상 마이크를 입력 장치로 설정하는 방법을 포함한다.
- `packages/audio-client/src/worklet.ts`: 입력을 모노로 합치고 실제 AudioContext 샘플레이트에서 24,000Hz로 리샘플링한다.
- `packages/contracts/src/audio.ts`: 전송 규격은 `pcm16`, `sampleRate: 24000`, `channels: 1`이며 PCM 청크를 Base64로 전달한다.
- `packages/ai/src/provider.ts`의 `pcm16ToWav`: 24kHz·모노·16비트 little-endian PCM을 WAV로 변환한다.
- WAV는 테스트 음성의 저장·재생 형식이다. 가상 마이크를 통해 재생한 음성은 기존 서비스의 캡처·변환 흐름을 거쳐 입력된다.
