# 서비스 랜딩페이지 및 소개 영상

상태: 최종

## 목표

현재까지 구현된 서비스를 바탕으로 사이트 기본 주소를 랜딩페이지로 구성한다. 방문자가 서비스의 필요성, 주요 기능, 핵심 기술을 이해하고 랜딩페이지에서 실제 서비스로 이동할 수 있게 한다.

대상 프로젝트: `/Users/gnar/orca/projects/DevDay-Hackathon`

## Astra에 맡길 범위

현재 구현된 서비스를 바탕으로 랜딩페이지를 구현하고, 상단 서비스 동작 소개 영상과 주요 기능별 짧은 화면 영상을 제작한다. 사이트 기본 주소에서 랜딩페이지가 열리고, 바로가기 버튼으로 실제 서비스에 진입하도록 연결한다.

실제 서비스의 진입 경로는 Astra가 프로젝트 구조를 확인해 결정한다.

## 원하는 결과

- 사이트 기본 주소에서 표시되는 랜딩페이지
- 랜딩페이지에서 실제 서비스로 이동하는 바로가기 버튼
- 상단에 사용할 서비스 동작 소개 영상
- 주요 기능별로 사용할 짧은 화면 영상

## 페이지 구성과 동작

아래 순서로 구성한다.

1. **상단 소개 영역**: 서비스가 동작하는 영상과 서비스 바로가기 버튼을 배치한다.
2. **왜 우리 서비스를 써야 하는가?**: 서비스를 사용해야 하는 이유를 설명한다.
3. **주요 기능**: 기능별 설명과 해당 기능의 짧은 화면 영상을 배치한다. 기능 항목마다 영상과 설명의 좌우 위치를 번갈아 구성한다.
4. **핵심 기술**: 서비스에 사용된 핵심 기술을 소개한다.

Astra가 프로젝트의 현재 구현을 확인해 서비스 사용 이유, 소개할 주요 기능, 핵심 기술을 선정하고 설명 문구까지 작성한다.

## 영상 제작 방식과 참고 자료

상단 서비스 동작 소개 영상과 주요 기능별 짧은 화면 영상은 실제 서비스 화면을 녹화하고, 그 위에 모션그래픽을 더하는 방식으로 제작한다.

[Career Hacker Alex — 따라 만드는 모션그래픽 160](https://www.careerhackeralex.com/sharings/cha-motion-kit)의 모션그래픽 정보를 활용해 영상을 제작한다.

참고 페이지는 모션 예제 MP4, 프롬프트, 일부 편집 소스를 제공한다. 페이지의 안내 내용을 확인했으며, 개별 예제 영상과 편집 소스는 아직 검토하지 않았다. 사용할 모션 예제는 Astra가 영상 내용에 맞게 선정한다.
