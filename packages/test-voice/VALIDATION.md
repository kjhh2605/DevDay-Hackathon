# 혼용·무작위 단어 간격 및 실제 BlackHole 검증

검증일: 2026-10-09. macOS, Node 24.20.0, pnpm 10.33.2, 실제 Chrome, BlackHole 2ch, 로컬 live 서비스(`http://localhost:5188`)에서 수행했습니다. 기존 서비스 코드 변경 없이 독립 패키지와 정상 서비스 HTTP/UI를 사용했습니다.

## 결과

**가상 마이크 → 브라우저 → 서비스 전사 수집 경로는 확인했습니다. 혼용 발화의 인식 정확도는 통과로 판정하지 않습니다.**

| 파일 형식         | 모두 WAV, signed PCM16 LE, 24,000 Hz, 모노                                   |

나머지 3개는 생성·파일 규격·무음 간격을 검증했으며, 이번 실제 루프백 재생 대상에는 포함하지 않았습니다. 테스트는 한 Mac에서 수행했으며 두 물리 장치 간 테스트나 최종 학습 피드백 승인은 포함하지 않습니다.

## 발견한 인식 오류

1~10초 간격으로 분리된 짧은 단독 발화에서 아래 결과가 나왔습니다. 원문을 정확하게 인식했다고 판정할 수 없습니다.

| 의도한 발화                 | 실제 raw 전사 예                   |
| --------------------------- | ---------------------------------- |
| `예약`                      | `Về呀`                             |
| `품절`                      | `혼자`                             |
| `눈치가`                    | `눈치가` (일치)                    |
| `보여서`                    | `ぽーやーさ`                       |
| `말을`                      | `말해.`                            |
| `못`                        | `موت`                              |
| `했어요`                    | `했어요.` (일치)                   |
| `미뤘어요`                  | `밀었어요.`                        |
| 영어 `to`, `for`, `feeling` | `Two`, `Four`, `Ceiling` 등의 혼동 |

한국어 단일 언어 샘플에서도 `지난` → `Sinan`, `타고` → `Taco` 등의 혼동이 있었습니다. 단어별 합성 억양과 긴 무음 때문에 문맥이 끊기는 조건입니다. TTS 발음·입력 음성 처리·전사 모델 가운데 어느 요인이 주원인인지는 이 결과만으로 확정하지 않습니다.

추가로 원본 WAV의 한국어 단어 PCM만 추출하고 0.5초 간격으로 연결해 `gpt-4o-transcribe` / `language=ko`로 별도 전사했습니다. 결과는 `예야, 눈치가 보여서 말을 못 했어요.`로, 이 검사에서도 일부 단어가 빠졌습니다. 이는 루프백을 거치지 않은 별도 ASR 검사이며, 사람의 청취 평가나 원본 TTS 정확도 인증은 아닙니다. 따라서 결과는 `recognitionStatus: needs-review`로 기록합니다.

## 실행기와 증거

최종 UI 화면 자동 저장에서 Playwright screenshot이 30초 시간 초과되어, 원래 실행 JSON과 프로세스 종료 결과는 **실패 상태를 그대로 보존**했습니다. 음성 재생·마이크 종료·84개 전사 조회는 그 전에 완료됐고, `finally`에서 장치도 복원했습니다. 읽기 전용 분석기로 저장된 결과를 다시 확인한 오디오 경로 판정은 `transportStatus: passed`입니다.

실행기는 화면 저장을 제한 시간 10초의 선택적 증거로 처리하도록 수정했습니다. 이 수정 뒤 유료 루프백 전체를 다시 실행하지는 않았습니다. 테스트 중간 화면은 별도 네이티브 캡처로 보존했습니다.
