Design System

컬러·타이포·아이콘 기준입니다. Na:viK 디자인 시스템의 구조(100~900 스케일, Base, Opacity, Point, Background, Pretendard + Montserrat, Material Symbols)를 따르고, 색만 보라 중심으로 다시 설정했습니다.

v0.1 · 2026-10-08라이트 확정 · 다크 제안tokens.css

컬러

각 색은 100(가장 연함)부터 900(가장 진함)까지 9단계입니다. 500이 대표색이고, 100은 배경, 200~300은 스트로크, 700 이상은 글자용입니다.

대비 검증

WCAG 2 기준으로 계산한 값입니다. 본문·버튼 글자는 4.5 이상, 큰 글자(18px 굵게 이상)는 3.0 이상이면 통과입니다.

타이포그래피

Pretendard가 UI 메인 서체입니다(400/500/600/700). Montserrat는 영문·숫자 단독 표기(표현 카드 제목, 타임스탬프, 통계 숫자)에만 씁니다. 국문과 영문이 섞인 문장은 영문도 Pretendard로 둡니다.

아이콘

아이콘은 Iconify의 Material Symbols 세트를 씁니다. 크기는 내비게이션 20px, 버튼 안 1.2em, 단독 24px이고 색은 글자색 토큰을 따릅니다(fill: currentColor).
